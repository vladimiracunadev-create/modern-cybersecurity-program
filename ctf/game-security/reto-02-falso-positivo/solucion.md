# Solución — ¿Snap o experto?

Reaction time aislado no separa A y B. Hay que correlacionar giro angular amplio, aceleración
angular, instante de visibilidad y disparo sobre ventanas repetidas; dispositivo/sensibilidad deben
estratificarse. El resultado es candidato a revisión, no ban automático. Se conserva versión de
regla, evidencia y explicación alternativa.
