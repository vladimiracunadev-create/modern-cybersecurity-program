## Qué significa cada nivel

Que el identificador «CWE-89» aparezca en un archivo **no** cuenta como cobertura. Los niveles son acumulativos y los tres últimos exigen un archivo que exista y que trate el tema.

| Nivel | Qué prueba |
|---|---|
| mencionado | El identificador aparece en algún documento. No se afirma que se enseñe. |
| explicado | Una clase declarada desarrolla la debilidad (causa, mecanismo, consecuencia). |
| con ejercicio | Una clase declarada la practica con un ejercicio, laboratorio guiado o reto. |
| con laboratorio | Un laboratorio ejecutable la reproduce en un entorno local. |
| con corrección y prueba | El laboratorio incluye la corrección y una prueba automática que la verifica. |

**Estado.** *Completo*: explicado + práctica + mitigación enseñada + verificación (prueba o evaluación). *Parcial*: tiene teoría o práctica pero le falta alguna otra pieza. *Pendiente*: como mucho se menciona.

## Cómo actualizar esta matriz
